# QA Portfolio - Jessica

## 📌 Project 1: Registration Page Test Case Design

Designed comprehensive test cases for a registration page using Equivalence Partitioning and Boundary Value Analysis.

**Coverage Highlights:**
- Input validation (Username, Email, Phone number, Password)
- Boundary value analysis (e.g., password length 5, 6, 12, 13)
- Security & edge cases (Rate limiting for verification codes, password visibility toggle, password case-sensitivity)
- Exception handling (Network failure, duplicate submission prevention)
- Database/backend validation (SQL data insertion, password hashing, dirty data check)

**Tools used:** Xmind
